## 📖 О проекте

Это учебный проект, написанный в процедурном стиле. Игра загадывает случайное слово из словаря, а игрок должен угадать его по буквам.
За каждую ошибку рисуется новая часть виселицы. Игра учитывает регистр букв, поддерживает русский алфавит (включая «Ё») и защищена от ввода повторных ошибок.

## ✨ Особенности

-   **Русская локализация:** Полностью на русском языке (интерфейс и ввод).
-   **Поддержка буквы «Ё»:** Специальная обработка редкой буквы русского алфавита.
-   **Защита от спама:** Повторный ввод одной и той же (даже неправильной) буквы не увеличивает счетчик ошибок.
-   **Динамическая графика:** Виселица отрисовывается пошагово через текстовые блоки (Text Blocks).
-   **Интерактивное меню:** Возможность начать игру заново или выйти в главное меню без перезапуска программы.
-   **Clean Code:** Код соответствует современным стандартам именования и обработки исключений (после прохождения ревью).

## ▶️ Как запустить

1.  **Клонируйте репозиторий:**
    ```bash
    git clone https://github.com/MaestroVLG/HangmanGame.git
    cd HangmanGame
    ```

2.  **Создайте файл словаря:**
    В корневой папке проекта создайте текстовый файл с именем `dictionary.txt`.
    Впишите в него слова (по одному слову на строку), например:
    ```text
    программирование
    архитектура
    виселица
    джава
    ```

3.  **Скомпилируйте код:**
    Откройте терминал в папке проекта и выполните:
    ```bash
    javac HangmanGame.java
    ```

4.  **Запустите игру:**
    ```bash
    java HangmanGame
    ```
